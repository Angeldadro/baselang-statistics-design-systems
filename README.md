# Baselang Statistics Design Systems

Carpeta con 5 alternativas visuales completas para el sistema de estadisticas de Baselang.

Cada alternativa usa la misma estructura de informacion para comparar estilo contra estilo sin cambiar el contenido:

- `executive.html` + `styles/executive.css`: dashboard ejecutivo, limpio y corporativo.
- `people-analytics.html` + `styles/people-analytics.css`: dashboard humano, calido y enfocado en HR.
- `intelligence.html` + `styles/intelligence.css`: dashboard oscuro, denso y analitico.
- `atlas.html` + `styles/atlas.css`: dashboard global, educativo y geografico.
- `pulse.html` + `styles/pulse.css`: dashboard moderno, expresivo y memorable.

Abre `index.html` para navegar entre las alternativas.

## Criterio de Comparacion

Los 5 documentos incluyen los mismos modulos base:

- Resumen global.
- Estructura organizacional por departamentos.
- Modalidad contractual y distribucion laboral.
- Sanciones.
- Ubicacion geografica.
- Antiguedad, modo de ingreso, demografia y formacion.

La intencion es elegir primero la direccion visual y luego convertir esa opcion en componentes reutilizables dentro del producto real.
